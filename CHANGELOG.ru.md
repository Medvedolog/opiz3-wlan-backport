# История изменений

[English](CHANGELOG.md)

## OpenWrt 25.12.6, текущий предрелиз — 29.10.2026

- Пересборка на официальной базе OpenWrt 25.12.6: Linux **6.12.112**, бэкпорт mac80211 **6.18.55**. Для плат H618 сохранён U-Boot 2026.04 проекта; поведение sysupgrade на sunxi не менялось.
- Из коммита `e38db9b` опубликованы образы microSD ext4 и squashfs для Zero 3, Zero 2W и Zero 2, соответствующий ImageBuilder для x86-64, манифесты и контрольные суммы.
- Подписанный APK-репозиторий 25.12.6 опубликован рядом с сохранённым репозиторием 25.12.5. Используйте репозиторий своей версии OpenWrt; не смешивайте модули ядра разных версий.
- Для этого выпуска подтверждена сборка в CI. Подробные проверки на платах относятся к **25.12.5 beta 2**, а не к отдельным испытаниям 25.12.6.

[Примечания к выпуску и скачивание](docs/releases/opiz3-25.12.6-latest.md#по-русски)

## OpenWrt 25.12.5

- [Текущий предрелиз ветки 25.12.5](https://github.com/Medvedolog/opiz3-wlan-backport/releases/tag/opiz3-25.12.5-latest): LuCI перестала показывать выдуманный уровень сигнала клиентов; добавлена страница AmneziaWG 2.0/3.1.
- [Beta 2](docs/releases/opiz3-25.12.5-beta2.md): исправлены запуск точки доступа при первой загрузке и Ethernet после перезагрузки Zero 3, добавлен образ Zero 2W и обновлено восстановление UWE5622. Репитер AP+STA остался экспериментальным. Более поздние отчёты по Zero 2 записаны в [плане и результатах испытаний](docs/TEST-PLAN.md).
- [Beta 1](docs/releases/opiz3-25.12.5-beta1.md): первая бета на официальном ядре OpenWrt со встроенным Wi-Fi UWE5622 и подписанным APK-репозиторием проекта.
